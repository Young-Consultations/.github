# AI-SDLC 3.0.1 corrective release candidate

**Status:** unpublished PATCH candidate.

Published `ai-sdlc-v3.0.0` remains immutable and remains the current published
compatibility release. The portfolio source consumer is still pinned to 2.4.5.

## Why this PATCH exists

Deployed Runtime Preflight run 36370005352 failed before any Codex execution
because the credential auditor reported
`AI_SDLC_RESULT_WRITER_PRIVATE_KEY` missing from consulting-playbook.

That private key is intentionally stored as an organization Actions secret with
repository access restricted to `Young-Consultations/consulting-playbook`.
The 3.0.0 preflight implementation inspected only repository/environment secret
metadata, so it could not recognize the approved organization-secret storage
scope. Organization issue #93 tracks this false-negative prerequisite defect.

This is a PATCH under the approved release policy. The reusable workflow
interface, permissions, payload contract, result-writer identity, receiver
behavior, registry semantics, and target adapter do not change.

## Corrected Runtime Preflight behavior

A required repository secret role passes when either:

1. the secret exists directly at repository scope; or
2. an organization Actions secret of the same name exists under the repository
   owner, has `selected` visibility, and explicitly selects the exact
   repository.

Runtime Preflight never reads the secret value. Broader organization-secret
visibility does not satisfy this reviewed boundary.

`PREFLIGHT_AUDIT_TOKEN` must be able to read organization Actions secret
metadata and the selected-repository list in addition to its existing
repository/environment metadata permissions.
