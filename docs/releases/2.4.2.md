# AI-SDLC 2.4.2 release repair

**Status:** target published; the `ai-sdlc-v2.4.2` control-plane release remains
an unpublished candidate.

This patch repairs the immutable-release drift exposed by portfolio issue #145.
It does not change the closed v2 payload schemas or create a new execution path.
The published `ai-sdlc-v2.4.1` control plane remains the active rollback baseline
until this sequence completes.

## Release composition

- Source consumer: production `portfolio-tasks` remains pinned to
  `codex-router.yml@ai-sdlc-v2.4.1` until final publication.
- Candidate router: `codex-router.yml` self-pins
  `actions/codex-router@ai-sdlc-v2.4.2`.
- Candidate receiver: `codex-result-receiver.yml` self-pins its action bundle
  to `ai-sdlc-v2.4.2`.
- Enabled target: only `consulting-playbook`, pinned to published
  `codex-adapter-v2.4.2` at
  `6ce0bf941c10c0c37b51c90d433d39f377ccad85` with reviewed
  TC-MVP-CI-001 evidence.
- Activation remains the existing mutable
  `config/codex-activation.json` state; this repair does not enable another
  target.
- `release/current-runtime.json` records the candidate composition and must not
  be interpreted as deployed production state while `tag_published` is false.

## Required publication sequence

1. **Completed:** merge the consulting target 2.4.2 receiver repin after its
   complete zero-effect conformance passes.
2. **Completed:** create immutable `codex-adapter-v2.4.2` at exact target merge
   commit `6ce0bf941c10c0c37b51c90d433d39f377ccad85`.
3. Update the control-plane candidate to bind that exact target tag, commit, and
   report digest; run target compatibility, contract, SIM, and candidate runtime
   checks.
4. Merge the reviewed control-plane candidate with `tag_published: false` and
   `tag_commit_sha: null`.
5. Create immutable `ai-sdlc-v2.4.2` at the exact reviewed control-plane merge
   commit.
6. Record the resolved control-plane tag commit in a publication-attestation
   change, set `tag_published: true`, regenerate the runtime record, and pass
   the publishable release and deployed Runtime Preflight gates.
7. Only after the control-plane tag resolves and verification passes, merge the
   portfolio consumer repin from `ai-sdlc-v2.4.1` to
   `ai-sdlc-v2.4.2`.
8. Run SIM, live verify, and one harmless REAL implement delivery with a fresh
   portfolio task identity. Issue #145 is terminal failed evidence and must not
   be reused.
